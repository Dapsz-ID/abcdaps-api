API REFERENCE / V1

API Documentation.

Dokumentasi penggunaan endpoint abcdaps-api untuk mengambil metadata dan URL media dari TikTok dan Instagram.

01. Pengenalan

API menerima URL konten publik dan mengembalikan hasil dalam JSON. Endpoint menerima request GET maupun POST. Ganti https://your-domain.vercel.app dengan domain deployment Anda.

URL media dan respons dapat bergantung pada perubahan platform serta ketersediaan layanan sumber pihak ketiga.

02. Quick start

Contoh request menggunakan cURL:

cURL · GET
curl -G "https://your-domain.vercel.app/api/tiktok" \\
  --data-urlencode "url=https://www.tiktok.com/@user/video/1234567890123456789"
JavaScript · fetch
const mediaUrl = "https://www.instagram.com/reel/REPLACE_ME/";
const endpoint = new URL("https://your-domain.vercel.app/api/instagram");
endpoint.searchParams.set("url", mediaUrl);

const response = await fetch(endpoint);
const result = await response.json();

console.log(result);

03. TikTok endpoint

GET / POST/api/tiktok

Ekstraksi video, image slide, profil kreator, statistik, musik, challenge, dan variasi bitrate bila tersedia.

Query parameters

ParameterWajibKeterangan
urlYaURL video/foto TikTok atau ID video yang didukung.
POST · JSON
fetch("/api/tiktok", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    url: "https://www.tiktok.com/@user/video/1234567890123456789"
  })
});

Jenis media ditandai melalui data.type: video atau image_slide. Video dapat berisi no_watermark_url, watermark_url, adaptive_bitrates, dimensi, dan durasi.

04. Instagram endpoint

GET / POST/api/instagram

Mengambil tautan video, gambar carousel, thumbnail, atau hasil mode audio.

ParameterWajibKeterangan
urlYaURL Instagram Reel, post, atau konten yang didukung.
mode=audioTidakMemanggil sumber audio dan mengembalikan daftar media/audio yang tersedia.
Mode audio
curl -G "https://your-domain.vercel.app/api/instagram" \\
  --data-urlencode "url=https://www.instagram.com/reel/REPLACE_ME/" \\
  --data-urlencode "mode=audio"

05. Response format

Respons sukses menggunakan struktur konsisten:

{
  "success": true,
  "status_code": 200,
  "data": {
    "type": "video",
    "source_url": "https://..."
  },
  "timestamp": 1790000000000
}

Field di dalam data mengikuti jenis platform dan media yang ditemukan. Timestamp menggunakan Unix epoch dalam milidetik.

07. Catatan penggunaan

  • Gunakan konten yang Anda miliki atau memiliki izin untuk mengunduh.
  • Konten privat, dihapus, dibatasi wilayah, atau memerlukan login mungkin tidak bisa diekstrak.
  • Provider pihak ketiga dapat berubah, membatasi request, atau tidak tersedia sewaktu-waktu.
  • Untuk deployment publik, tambahkan rate limiting dan monitoring sebelum membuka akses luas.
  • Jangan mengandalkan URL hasil ekstraksi sebagai penyimpanan permanen.
